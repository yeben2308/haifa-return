# המשך עבודה — דשבורד מיגון מוסדות חינוך, מחוז חיפה (נכתב 8/11/2026, מהנייד)

## מטרה
דשבורד מיגון לכל מוסדות מחוז חיפה, בתוך גיליון Google, עם מידור לפי מיילים (מנהל / מחוז / רשות / מפקח).
נתוני מוסד נמשכים אוטומטית מ"הכל אודות מוסד"; נתוני מיגון מעדכנים קב"טי הרשויות; בנוסף הנחיות פיקוד העורף לכל ישוב.

- גיליון "מקלוט מוסדות חינוך — מחוז חיפה" (תיקיית חירום ב-Drive של 1002026036@edu-haifa.org.il) + Apps Script, Web App גרסה 28.
  לשוניות: מוסדות_אתר (3,526×151), אתר_לחיבור, מקלוט (2,323, לקב"טים), מאוחד (נוסחאות, 3,578), פיקוד_העורף (92 ישובים), הרשאות, יומן, יומן שינויים.
- משיכה יומית אוטומטית של המוסדות: משימת Windows "Maklot Haifa daily" 06:30 במחשב הנייד → C:\Users\yochi\maklot-auto\run.mjs → auto_pull.mjs (Puppeteer).
- דשבורד: כניסה בקוד למייל (Auth.gs), מידור בשרת, עיצוב "שילוט פיקוד העורף" (סקיל impeccable), סמל המדינה בכותרת,
  מסך עדכון לקב"ט (עריכה במקום + יומן שינויים), פאנל פיקוד העורף בסינון רשות ובפרטי מוסד, קישור חי לכל ישוב באתר פיקוד העורף.
- כתובת קצרה: https://migun-haifa.netlify.app (iframe + תצוגה מקדימה לווטסאפ). דף התקנת סימניות: /install.html.
- פיקוד העורף: מתעדכן רק בכפתור. מנהל לוחץ "עדכון פיקוד העורף" בדשבורד → נפתח האתר → לוחץ סימנייה → הדשבורד מציג פס ירוק בסיום.
- תוקן באג תקיעה: HtmlService חותך הכול אחרי // גם במחרוזות → בתוך <script> לכתוב https:\/\/ .

## החלטות
- פיקוד העורף חוסם דפדפן אוטומטי (CloudFront 403) ולא מאפשר iframe/CORS. לא עוקפים: נוסה תוסף Chrome — מסווג ההרשאות חסם כ"עקיפת בדיקת בוטים".
  אוטומציה מלאה רק באישור רשמי — טיוטה מוכנה (פנייה_לפיקוד_העורף.md). לא להציע שוב תוסף/headful/userscript.
- שרת בחו"ל (GitHub Actions/Railway) לא מגיע לאתרי המשרד — המשיכה רצה רק ממחשב בישראל.
- המפתח הסודי PUSH_TOKEN נמצא רק ב-apps-script/Config.gs (מוחרג מ-git). לא להדפיס אותו; Node קורא אותו מהקובץ.
- המאגר haifa-return ציבורי — לא להעלות אליו את maklot-sync.

## מה נשאר / הצעד הבא
1. **ראשון:** לבקש מהמשתמש להיכנס ל-https://migun-haifa.netlify.app עם קוד מהמייל ולוודא שהדשבורד נטען (אחרי תיקון התקיעה, גרסה 27-28; טרם נבדק בכניסה אמיתית).
2. בדיקת עדכון פיקוד העורף מהדשבורד (כפתור → סימנייה → פס ירוק). הסימנייה מותקנת מ-/install.html.
3. בדיקת שמירה אמיתית במסך העדכון של קב"ט (להוסיף בלשונית הרשאות שורה "רשות"/"חדרה" ולבדוק).
4. **שימו לב במחשב העבודה:** המשיכה היומית רצה ממשימת Windows במחשב הנייד בלבד. אם רוצים שתרוץ גם/במקום מחשב העבודה —
   ליצור שם את C:\Users\yochi\maklot-auto\run.mjs ואת המשימה (ההוראות ב-README.md, סעיף "עדכון יומי").
5. clasp במחשב העבודה: עותק העבודה C:\Users\yochi\clasp-maklot קיים רק בנייד. במחשב העבודה: clasp clone 1hxKsgTFn_6nd_1LeLQXHU6kfrJQBcM_hmRQr0YhVJSxC8FC_LTup5uyW לתיקייה זו (מחוץ ל-OneDrive).
